# Netflix Movies & TV Shows Analytics Dashboard

## 📊 Project Overview

An interactive **Netflix Movies and TV Shows Analytics Dashboard** developed using **Tableau Public** to analyze Netflix content based on ratings, genres, countries, release years, date added, duration, and content type.

The dashboard provides interactive filtering and visualizations to help understand Netflix's content distribution and trends.

## 🎯 Objectives

* Analyze Netflix Movies and TV Shows data.
* Understand content distribution by country.
* Analyze ratings and content types.
* Identify popular genres.
* Analyze year-wise content trends.
* Compare Movies and TV Shows.
* Provide interactive filtering for data exploration.

## 📌 Dashboard Features

### 1. Country-wise Content Map

A filled geographical map showing the number of Netflix Movies and TV Shows by country.

Darker colors represent countries with a higher number of titles.

### 2. Ratings Analysis

A bar chart showing the distribution of Netflix titles across different ratings such as TV-MA, TV-14, TV-PG, PG-13, R, and others.

### 3. Movies vs TV Shows Distribution

A visual comparison of the total number of Movies and TV Shows available in the dataset.

### 4. Top 10 Genres

A bar chart highlighting the top 10 genres based on the number of Netflix titles.

### 5. Year-wise Content Analysis

A trend visualization showing the number of Movies and TV Shows added over different years.

### 6. Description

An interactive description section that displays the description of the selected title.

## 🔎 Interactive Filters

The dashboard includes:

* Type filter
* Title filter
* Relevant-value filtering
* Cross-worksheet filtering

The Type and Title filters are applied across multiple worksheets including:

* Rating
* Duration
* Date Added
* Release Year
* Genre
